# Argentum

A modern Webshop built with Next.js, integrating Stripe for payments and Supabase for backend services.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org) 16
- **Database & Auth**: [Supabase](https://supabase.com)
- **Payments**: [Stripe](https://stripe.com)
- **Styling**: [Tailwind CSS](https://tailwindcss.com)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)
- **Icons**: [Lucide React](https://lucide.dev/)

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Architecture

This project is structured using the App Router in Next.js. It integrates with Stripe for handling e-commerce transactions and Supabase as a backend-as-a-service for database and authentication.
